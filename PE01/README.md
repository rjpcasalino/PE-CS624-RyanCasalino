# CS624 - Practice Exercise 01 (PE01): Hello World

An introductory React Native mobile application for **City University of Seattle's CS624 (Full-Stack Development - Mobile App)**.

## Overview

The application displays:
- Student Name: Ryan Casalino
- Degree Program: MSCS (Master of Science in Computer Science)
- School: STC (School of Technology & Computing)
- Styling: Centered text layout with a distinctive yellow background (`backgroundColor: 'yellow'`).

## Running the App

```bash
cd HelloWorld
npm install
npx expo start
```
